日本語・英語・簡体中文・繁体中文の4行からなる表で回答していること。

そのうえで、繁体中文が簡体中文からの字体変換ではなく、台湾の國語として訳されていること。具体的に次を全て満たす。

- 地下鉄が「捷運」であること。「地鐵」は不可。
- じゃがいもが「馬鈴薯」であること。「土豆」は不可。
- サーバーが「伺服器」であること。「服務器」は不可。

簡体中文側は「地铁」「土豆」「服务器」であること。

英語は subway / supermarket / potatoes / server を含む自然な英文であること。

「了」の有無や、細かい語順・言い回しの違いは減点しない。

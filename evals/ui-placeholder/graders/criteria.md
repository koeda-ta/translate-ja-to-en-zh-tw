判定の前に、回答から判定対象を抽出する。

１. 回答の中の表を探し、日本語・英語・簡体中文・繁体中文の4行を取り出す。
２. 取り出した4行の訳文だけを判定対象とする。
３. 表より後ろの文章（補足・注・確認事項・実装上の助言など）は判定対象から除外する。以降の項目を確認する際、除外した文章は読まなかったものとして扱う。

除外した文章に「実際には | に戻してください」「&#124; は表を壊さないための表記です」といった記述があっても、判定には一切使わない。これらは訳文の品質とは無関係な運用上の注意であり、訳文が下記を満たしていれば合格とする。

抽出した4行について、次を判定する。

- 4言語が揃った表になっていること。
- プレースホルダ %{count} が改変されず、そのままの綴りで残っていること。
- HTML タグが <a href="..."> と </a> の形で残っていること。山括弧をバックスラッシュでエスケープした \<a ...\> は不可。
- タグの中身（href の値）が翻訳されていないこと。
- href の属性値に含まれる半角の | が HTML エンティティ &#124; に置き換えられていること。\| でのエスケープは不可。
- 各訳文が1行で、改行を含まないこと。

繁体中文でファイルが「檔案」、ヘルプが「說明」など台湾のUI用語になっていること。簡体中文は「文件」「帮助」。
